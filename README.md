# 📊 Simulador de Investimentos

## 📌 Sobre o projeto

Este projeto consiste em um simulador de investimentos desenvolvido no Microsoft Excel para realizar projeções financeiras de longo prazo.

A ferramenta permite inserir informações como salário, valor do aporte mensal, período de investimento e taxa de rendimento, gerando estimativas do patrimônio acumulado e dos dividendos mensais.

O projeto também permite analisar diferentes cenários de investimento e visualizar uma sugestão de distribuição dos aportes entre diferentes tipos de Fundos de Investimento Imobiliário (FIIs), de acordo com o perfil selecionado.

## 🎯 Objetivo

O objetivo do projeto é aplicar conhecimentos de Excel e cálculos financeiros na criação de uma ferramenta prática para simulação e planejamento de investimentos.

Através da ferramenta, é possível visualizar como o valor dos aportes, o tempo e a taxa de rendimento podem influenciar a formação de patrimônio ao longo dos anos.

## ⚙️ Funcionalidades

* Simulação de investimentos mensais;
* Projeção de patrimônio acumulado;
* Estimativa de dividendos mensais;
* Análise de diferentes períodos de investimento;
* Seleção de perfil de investimento;
* Distribuição dos aportes entre diferentes tipos de FIIs;
* Comparação de cenários de longo prazo.

## 📈 Cenários analisados

A planilha apresenta projeções para diferentes períodos:

* 2 anos;
* 5 anos;
* 10 anos;
* 15 anos;
* 20 anos;
* 25 anos;
* 30 anos.

Esses cenários permitem observar a evolução projetada do patrimônio ao longo do tempo.

## 👤 Perfis de investimento

A ferramenta apresenta três perfis de investimento:

### 🟢 Conservador

Apresenta uma distribuição de aportes com uma composição mais conservadora.

### 🟡 Moderado

Apresenta uma distribuição intermediária entre diferentes categorias de FIIs.

### 🔴 Agressivo

Apresenta uma distribuição com maior exposição a categorias com maior potencial de valorização e, consequentemente, maior risco.

## 🏢 Tipos de FIIs

A ferramenta considera diferentes categorias de Fundos de Investimento Imobiliário:

* Papel;
* Tijolo;
* Híbridos;
* FOFs;
* Desenvolvimentos;
* Hotelarias.

## ⚠️ Observação

Este projeto possui finalidade exclusivamente educacional.

Os valores apresentados são simulações matemáticas e não representam recomendação de investimento ou garantia de rentabilidade futura.

As taxas, percentuais e demais parâmetros utilizados devem ser considerados apenas para fins de estudo e simulação.
